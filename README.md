# 基于供需匹配的长护辅具租赁调度监管系统 · Streamlit Demo

面向长护险辅具租赁场景的 **物联网感知 → 时空融合 → 图谱反演 → 异常监管 → 供需调度 → 自适应反馈** 全链路演示。

## 在线访问

部署后通过 Streamlit Cloud 访问（固定网址）。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 界面板块

1. 总览看板：KPI、使用频率趋势、异常分布、设备位置图
2. 行为-状态反演：图神经网络 + 注意力机制的状态分级
3. 合规异常监管：两类违规（位置偏离 / 维保失真）
4. 供需调度：漂移率、调度决策、供给-需求雷达图
5. 自适应反馈：强化学习收敛度与采样率轨迹
